How to Enable AI Features

Run the following command in your terminal:

install_ai.bat (Windows)

Or manually install:

pip install torch transformers sentence-transformers scikit-learn numpy
Note: This will download approximately 500MB of AI models. Installation takes 5-10 minutes.

Frequently Asked Questions
Q: Is it free?

Yes! All AI features use free, open-source models. No API keys or monthly fees.

Q: How much space does it need?

Approximately 500MB for models and 1.5GB RAM when running.

Q: Can I use the site without AI?

Yes! All core features (shopping, cart, checkout) work without AI. AI just adds extra features.

Q: Need help?

Check AI_README.md or TROUBLESHOOTING.md in the project folder.
