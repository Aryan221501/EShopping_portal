### Model Used
- **DialoGPT-medium** by Microsoft
- 345M parameters
- Trained on Reddit conversations

1. **Conversation History**

   - Provides context for better responses

2. **Hybrid Approach**
   - Pattern matching for known intents (fast)

   - Product search integration (practical)

3. **Response Enhancement**
   - Adds store-specific context
   - Includes shipping/return info when relevant
   - Maintains friendly, helpful tone

4. **Smart Product Search**
   - Extracts keywords intelligently
   - Handles price filters
   - Searches title, description, and category
   - Shows up to 5 relevant products

## Customization

### Adjust AI Temperature
Edit `ai_services.py` line ~90:

```python
output = model.generate(
    ...
    temperature=0.7,  # Lower = more focused, Higher = more creative
    ...
)
```

- `0.5` = Very focused, predictable
- `0.7` = Balanced (current)
- `0.9` = More creative, varied

### Change Response Length
```python
max_length=input_ids.shape[1] + 50,  # Increase for longer responses
```

### Modify System Context
Edit `ai_services.py` line ~45:

```python
self.system_context = """Your custom instructions here"""
```

## Troubleshooting

### Issue: Slow responses
**Solution**: Normal for first message (model loading)
Subsequent messages should be fast

### Issue: Generic responses
**Solution**: 
1. Increase temperature (more creative)
2. Provide more context in message
3. Use conversation history (already implemented)

### Issue: Out of memory
**Solution**:
1. Use DialoGPT-small instead of medium
2. Reduce conversation history length
3. Clear history more frequently

### Issue: Model not downloading
**Solution**:
```bash
# Manually download
python -c "from transformers import AutoTokenizer; AutoTokenizer.from_pretrained('microsoft/DialoGPT-medium')"
```
